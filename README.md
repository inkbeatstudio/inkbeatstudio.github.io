# InkBeat Studio — Desktop

Десктоп-версія сайту-студії (Linux + Windows), що працює повністю
локально. Обгортка на Python (`pywebview`) + локальний HTTP-сервер,
всередині — той самий HTML/CSS/JS з `pages/studio` та `pages/master`
(еквалайзер, мастеринг, мультитрек, video-to-audio, vocal-split).

## Бібліотека, плагіни та семпли (нове)

Студія тепер має справжню файлову бібліотеку на диску — окрему від
самого застосунку, тож не втрачається при оновленнях:

```
~/InkBeatStudio/Library/
├── Samples/       твої аудіо-семпли
├── Instruments/   плагіни-інструменти (готові приклади: Warm Pluck, Deep Sub, Crystal Bell)
├── Effects/       плагіни-ефекти (готові приклади: Tape Delay, Bit Crusher, Stereo Chorus)
└── Projects/      збережені проєкти як окремі *.inkbeat.json файли
```

У студії — нова кнопка **«Бібліотека»** на панелі інструментів:
вкладки Семпли / Інструменти / Ефекти / Проєкти. Звідти можна:
- імпортувати аудіофайли в бібліотеку семплів (з категоріями Drums/Bass/Melodic/Vocals/FX) і додавати їх на доріжки;
- встановлювати нові плагіни через `.zip` (формат — див.
  `PLUGIN_DEV_GUIDE.md`);
- додавати встановлені ефекти-плагіни в ланцюг на майстер-шині;
- зберігати/відкривати проєкти як реальні файли (окремо від
  автозбереження в IndexedDB браузера, яке лишилось як було).

**У комплекті вже є стартовий контент** — нічого встановлювати не треба:

| Категорія | Що всередині |
|---|---|
| Інструменти (6) | Warm Pluck, Deep Sub, Crystal Bell, FM Bass, Analog Strings, Arp Pluck |
| Ефекти (6) | Tape Delay, Bit Crusher, Stereo Chorus, Hall Reverb, Stereo Widener, Auto Wah |
| Семпли (13) | Drums: Kick/Snare/HiHat×2/Clap/Tom×2/Rim/Shaker · Bass: Sub/Pluck · Melodic: Bell Chord/Pad Swell |

Усі семпли — оригінальні, синтезовані програмно (`tools/generate_sample_pack.py`), без жодного стороннього ліцензованого контенту, тож їх можна вільно використовувати й поширювати.

**Плагіни пишуться на чистому JS + Web Audio API**, без збірки —
теку з `plugin.json` + `main.js` можна написати вручну або
згенерувати. Повний опис формату, приклади коду та роадмап (включно з
місцем під майбутній AI-плагін) — у `PLUGIN_DEV_GUIDE.md`.

## Аналіз треку (нове, окрема вкладка)

Лаунчер → **🧬 Аналіз треку** (або кнопка «Аналіз» у верхній панелі студії).
Завантаж готовий мінус (mp3/wav/ogg/m4a/flac, наприклад зі Suno) — усе рахується локально в браузерному рушії
(`app/pages/analyzer/engine.js`), без моделей і без інтернету:

1. Темп (BPM, ÷2/×2 і альтернативи), сітка тактів, перший такт.
2. Тональність та акорди по тактах.
3. Ударні (kick / snare / hi-hat / open hat) як цикл 1/2/4 такти — клітинки можна правити.
4. Перевірка на слух: відтворення з кліком метронома поверх хвилі.
5. «Відкрити у студії» — створює проєкт: BPM, секвенсор, акорди в піано-ролі (легато, інструмент Analog Strings),
   оригінал окремою приглушеною доріжкою. Попередній проєкт зберігається як резервна копія.

Обмеження: мелодія/вокал/тембри не розпізнаються; темп вважається сталим (при дрейфі — попередження);
різкі ноти баса можуть читатися як kick; у щільному міксі snare може бути знайдений лише частково.
Тестувалось на синтетичних треках з відомою «правдою»:

```bash
python3 tools/make_test_track.py --bpm 96 --name t96      # WAV + JSON з правдою
node tools/test_engine.js t96.wav t96.json                # порівняння: BPM, 1-й такт, тональність, акорди, ударні
```

## Як це влаштовано

```
inkbeat-desktop/
├── app.py                # точка входу: піднімає локальний сервер + вікно
├── library_backend.py    # HTTP API бібліотеки (семпли/плагіни/проєкти на диску)
├── requirements.txt
├── build_linux.sh        # збірка .бінарника для Linux
├── build_windows.bat     # збірка .exe для Windows (запускати на Windows)
├── PLUGIN_DEV_GUIDE.md    # як писати свої плагіни-інструменти/ефекти
├── install_linux_desktop.sh # додає застосунок у меню застосунків Linux
├── tools/
│   └── generate_sample_pack.py # генератор стартового пак семплів (можна перегенерувати/розширити)
├── .github/workflows/
│   └── build-desktop.yml # авто-збірка ОБОХ версій у хмарі GitHub Actions
└── app/                  # сам сайт (launcher.html — стартова сторінка)
    ├── launcher.html     # новий екран-меню з усіма інструментами
    ├── vendor/jszip/      # jszip завантажено локально (не з CDN)
    ├── library-defaults/  # вбудовані приклади плагінів (копіюються в Library при першому запуску)
    ├── pages/studio/      # багатодоріжкова студія + бібліотека/плагін-система
    └── pages/master/      # еквалайзер, мастеринг, мультитрек, і т.д.
```

Чому не просто `file://index.html`? Мікрофон (`getUserMedia`),
запис через `MediaRecorder`, збереження проєктів у IndexedDB — все це
надійно працює лише в "secure context". `file://` таким не вважається
в більшості браузерних рушіїв, а `http://127.0.0.1` — вважається. Тому
`app.py` піднімає локальний HTTP-сервер на порту `127.0.0.1:47821` і
відкриває його у нативному вікні через `pywebview`.

Порт зафіксований (не випадковий), бо проєкти в студії зберігаються в
IndexedDB/localStorage браузера — вони прив'язані до `host:port`. Якщо
порт змінювався б щоразу, збережені проєкти "губилися" б між запусками.

## Запуск для розробки (Linux, зараз)

```bash
cd inkbeat-desktop

# Системні залежності для pywebview (GTK/WebKit бекенд на Linux):
sudo apt update
sudo apt install -y python3-gi python3-gi-cairo gir1.2-gtk-3.0 \
  gir1.2-webkit2-4.1 libgtk-3-dev

python3 -m venv --system-site-packages .venv
source .venv/bin/activate
pip install -r requirements.txt

python app.py
```

Прапорець `--system-site-packages` обов'язковий: модуль `gi` (GTK-біндінги
для Python) ставиться системним `apt`, а не через `pip`, і звичайний
ізольований venv його не бачить.

Відкриється нативне вікно з меню всіх інструментів. Правиш HTML/CSS/JS
у `app/` — перезапускаєш `python app.py` — одразу бачиш зміни.

## Збірка в один виконуваний файл (Linux)

```bash
./build_linux.sh
# результат: dist/InkBeatStudio — один файл, можна переносити на інший
# Linux-ПК (той самий дистрибутив/архітектура) без встановлення Python
```

## Збірка .exe для Windows

Два варіанти:

**1. Автоматично в хмарі (рекомендовано) — не потрібен Windows-ПК:**
   - Заливаєш цю теку в GitHub-репозиторій.
   - У вкладці **Actions** запускаєш workflow "Build Desktop App"
     (кнопка "Run workflow"), або пушиш тег `v1.0.0`.
   - Через кілька хвилин у результатах збірки (Artifacts) буде готовий
     `InkBeatStudio-windows` (.exe) і `InkBeatStudio-linux`.

**2. Вручну на Windows:**
   - Встанови Python 3.11+ з python.org.
   - Скопіюй цю теку на Windows-машину.
   - Запусти `build_windows.bat` (подвійний клік або з CMD).
   - Результат: `dist\InkBeatStudio.exe`.

   Про WebView2: на Windows 10/11 він майже завжди вже вбудований
   (частина Edge). Якщо вікно не відкривається — постав
   [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/).

## Відомі обмеження офлайн-режиму

- На головній сторінці сайту (`index.html`) блок "Останні релізи"
  тягне дані з SoundCloud через інтернет — офлайн він просто покаже
  повідомлення про помилку завантаження (це вже оброблено в коді,
  застосунок не падає). Сама студія та інструменти обробки звуку від
  цього не залежать.
- Шрифти Google Fonts підключені через CDN-посилання в `<head>` —
  офлайн вони не підвантажаться і браузер підставить системний шрифт
  (вигляд трохи інший, але все функціонує). За бажанням можна
  завантажити `.woff2`-файли й підключити локально — скажи, і я це
  зроблю.

## Реєстрація в меню застосунків Linux

Після збірки (`./build_linux.sh`) можна додати InkBeat Studio в меню
застосунків (щоб запускати як звичайну програму, не через термінал):

```bash
./install_linux_desktop.sh
```

## Наступні кроки / ідеї на майбутнє

- Іконка застосунку і `.desktop`-файл для Linux (щоб з'явився в меню
  застосунків) — можу додати.
- UI-регулятори для параметрів плагінів (зараз параметри є в
  `plugin.json`, але редагуються тільки з коду) — дивись
  `PLUGIN_DEV_GUIDE.md` → «Наступні кроки».
- Per-track (а не лише майстер-шина) ефекти-плагіни.
- Встановлювач (.msi / .AppImage) замість одного бінарника.
- AI-плагін (генерація мелодій, авто-мастеринг, розділення стемів) —
  архітектура плагінів вже готова це прийняти, коли дійде черга.
